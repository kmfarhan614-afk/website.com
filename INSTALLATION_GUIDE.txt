## 2. INSTALLATION STEPS

### Step 1: Download Files
1. Download all files from the distribution package:
   - index.html
   - style.css
   - script.js
   - README.md
   - config.json
   - QUICKSTART.html

### Step 2: Create Application Folder
```
C:\Users\[YourUsername]\Desktop\website.com\
```
Or any location of your choice.

### Step 3: Place Files
1. Copy all downloaded files into the folder
2. Ensure all files are in the SAME directory
3. Do NOT create subfolders for these main files

### Step 4: Verify Installation
Check that your folder contains:
```
website.com/
├── index.html
├── style.css
├── script.js
├── README.md
├── QUICKSTART.html
└── config.json
```

### Step 5: Launch Application
**Option A: Double-click**
- Double-click `index.html` to open in default browser

**Option B: Right-click and Select**
- Right-click `index.html`
- Select "Open with" → Choose your preferred browser

**Option C: Drag and Drop**
- Drag `index.html` into your browser window

**Option D: From Browser Menu**
- Open browser
- Press Ctrl+O (or Cmd+O on Mac)
- Navigate to and select `index.html`

## 4. CONFIGURATION

### Changing Academy Name
Edit `index.html` and find:
```html
<h1>The Lighthouse Academy</h1>
```
Replace with your academy name.

### Changing Colors
Edit `style.css` and modify the CSS variables:
```css
:root {
    --primary: #2563eb;          /* Main blue color */
    --secondary: #7c3aed;        /* Purple accent */
    --success: #10b981;          /* Green */
    --warning: #f59e0b;          /* Orange */
    --danger: #ef4444;           /* Red */
}
```

### Changing Logo/Icon
Replace the lightbulb icon in `index.html`:
```html
<i class="fas fa-lightbulb"></i>
```
With any Font Awesome icon. Visit: https://fontawesome.com/icons

### Updating Sample Data
1. Open `index.html` in a text editor
2. Find the table with sample student data
3. Replace names, emails, contact numbers with your data
4. Save and refresh the browser

### Adding/Removing Departments
Edit the departments section in `index.html`:
```html
<div class="dept-card">
    <!-- Copy and modify this card -->
</div>
```

## 5. TROUBLESHOOTING

### Issue: Page won't load or shows blank screen
**Solution:**
- Ensure all files are in the same folder
- Check if JavaScript is enabled in browser settings
- Try a different browser
- Clear browser cache (Ctrl+Shift+Delete)

### Issue: Icons not displaying
**Solution:**
- Check internet connection (icons load from Font Awesome CDN)
- Or download Font Awesome and use local copy
- Refresh the page (F5)

### Issue: Styles not applying
**Solution:**
- Verify style.css is in the same folder
- Check browser console for errors (F12)
- Clear browser cache
- Try opening in a different browser

### Issue: Search or filters not working
**Solution:**
- Verify JavaScript is enabled
- Check browser console (F12) for errors
- Refresh the page
- Try in a different browser

### Issue: Navigation buttons not responding
**Solution:**
- Clear browser cache
- Disable browser extensions
- Try in incognito/private mode
- Restart the browser

### Issue: Mobile sidebar not appearing
**Solution:**
- Resize browser window to trigger mobile view
- Check if hamburger menu (≡) is visible
- Try on actual mobile device
- Check browser's mobile emulation (F12)

### Issue: Performance is slow
**Solution:**
- Close unused browser tabs
- Disable unnecessary extensions
- Clear browser cache
- Use modern browser (Chrome or Firefox)
- Ensure sufficient system RAM

## 6. CUSTOMIZATION GUIDE

### Customizing Header
Edit `index.html`:
```html
<header class="header">
    <h1>Your Academy Name</h1>
    <p class="subtitle">Your Tagline Here</p>
</header>
```

### Adding New Navigation Items
1. Add to sidebar in `index.html`:
```html
<li><a href="#newsection" class="nav-link" data-section="newsection">
    <i class="fas fa-icon-name"></i> New Section
</a></li>
```

2. Add corresponding section:
```html
<section id="newsection" class="section">
    <!-- Your content here -->
</section>
```

### Customizing Color Scheme
Complete list of CSS variables in `style.css`:
```css
--primary: #2563eb              /* Main brand color */
--primary-dark: #1e40af         /* Darker shade */
--primary-light: #3b82f6        /* Lighter shade */
--secondary: #7c3aed            /* Secondary color */
--accent: #ec4899               /* Accent color */
--success: #10b981              /* Success green */
--warning: #f59e0b              /* Warning orange */
--danger: #ef4444               /* Error red */
--info: #06b6d4                 /* Info cyan */
--dark: #1f2937                 /* Text dark */
--gray: #6b7280                 /* Text gray */
--light-gray: #e5e7eb           /* Light gray */
--lighter-gray: #f3f4f6         /* Very light gray */
--white: #ffffff                /* White */
```

### Adding New Statistics Cards
In `index.html`, add to stats-grid:
```html
<div class="stat-card">
    <div class="stat-icon" style="background: #YOUR_COLOR;">
        <i class="fas fa-icon-name"></i>
    </div>
    <div class="stat-content">
        <h3>123</h3>
        <p>Your Label</p>
    </div>
</div>
```

### Customizing Font
Edit `style.css`:
```css
body {
    font-family: 'Your Font Name', fallback, sans-serif;
}
```

### Adding Notifications
Use JavaScript in console or script.js:
```javascript
showNotification('Your message', 'success');
// Types: success, error, warning, info
```

## 7. ADVANCED SETUP

### Hosting on Web Server
1. Upload all files to your web hosting server
2. Ensure files are in the same directory
3. Access via URL: `http://yoursite.com/index.html`

### Local Testing
Use Python Simple Server:
```bash
python -m http.server 8000
# or Python 3
python3 -m http.server 8000
```
Then visit: `http://localhost:8000/index.html`

### Adding to Existing Website
1. Create a folder: `yoursite.com/academy/`
2. Place all files in that folder
3. Link from main site: `<a href="/academy/index.html">Academy System</a>`

### Common Questions

**Q: Can I add my own students?**
A: Yes, edit the HTML table with your student data.

**Q: Will the data save?**
A: No, this version stores data in HTML. For persistent storage, add database backend.

**Q: Can I export to Excel?**
A: Currently exports to PDF. Excel export requires backend integration.

**Q: Is this mobile friendly?**
A: Yes, it's fully responsive and works on all devices.

**Q: Can I use this offline?**
A: Yes, except Font Awesome icons require internet.
