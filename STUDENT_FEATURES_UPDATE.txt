📋 HOW TO ADD STUDENTS (Easy 3-Step Process)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: NAVIGATE TO STUDENTS PROFILE
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Open the website (index.html)                                        │
│ 2. Click "Students Profile" in the left sidebar                        │
│ 3. You'll see the student database table                               │
└─────────────────────────────────────────────────────────────────────────┘

STEP 2: CLICK "ADD NEW STUDENT" BUTTON
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Look for the blue button at the top right                           │
│ 2. Button says: "+ Add New Student"                                    │
│ 3. Click it                                                             │
│ 4. A modal form will appear                                            │
└─────────────────────────────────────────────────────────────────────────┘

STEP 3: FILL IN STUDENT DETAILS
┌─────────────────────────────────────────────────────────────────────────┐
│ Fill in these fields:                                                   │
│                                                                         │
│ • Roll Number: 005 (or any unique number)                              │
│ • Student Name: Ahmed Hassan                                           │
│ • Department: Select from dropdown                                     │
│   - English Language                                                   │
│   - IT & Programming                                                   │
│   - Web Development                                                    │
│ • Class Level: Select from dropdown                                    │
│   - Beginner                                                           │
│   - Intermediate                                                       │
│   - Advanced                                                           │
│ • Email: student@email.com                                            │
│ • Contact: +966-555-0000                                              │
│ • Admission Date: 2026-06-04                                          │
│                                                                         │
│ Then click "Add Student" button                                        │
└─────────────────────────────────────────────────────────────────────────┘

RESULT:
✅ Student added successfully
✅ Notification appears
✅ Student appears in table immediately
✅ Data is saved (persists when you refresh page)

🔍 VIEWING & SEARCHING STUDENTS
═══════════════════════════════════════════════════════════════════════════════

VIEW ALL STUDENTS:
1. Click "Students Profile" in sidebar
2. All students display in table below
3. Includes your added students + sample students

SEARCH BY NAME:
1. Use the search box at top of table
2. Type student name
3. Results filter automatically as you type

FILTER BY DEPARTMENT:
1. Click dropdown that says "All Departments"
2. Select: English Language / IT & Programming / Web Development
3. Only students from that department show

FILTER BY CLASS:
1. Click dropdown that says "All Classes"
2. Select: Class 1 / Class 2 / Class 3
3. Only students at that level show

COMBINE FILTERS:
1. Search by name AND filter by department
2. Both filters work together
3. Results narrow down with each filter

🗑️ DELETING STUDENTS
═══════════════════════════════════════════════════════════════════════════════

HOW TO DELETE A STUDENT:
1. Find the student in the table
2. Click the trash icon (🗑️) in the Action column
3. A confirmation dialog appears
4. Click "OK" to confirm deletion
5. Student is removed from table
6. Success notification appears
7. Data updates immediately

IMPORTANT:
⚠️ This action cannot be undone!
⚠️ Student will be permanently deleted
⚠️ No backup is kept

❓ FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Will my students be deleted if I close the browser?
A: No! Data is saved in localStorage and persists permanently.

Q: Can I edit a student after adding them?
A: Current version: Delete and re-add
  Future version: Direct edit functionality coming

Q: How many students can I add?
A: Theoretically unlimited (browser limit ~5-10MB)

Q: Can I export the student list?
A: Current: Screenshot or print (Ctrl+P)
  Future: Excel export coming

Q: Is my data backed up?
A: Data is on your device only. We recommend:
  - Regular screenshots
  - Manual exports
  - Cloud backup using browser sync

Q: Can multiple people use this?
A: Each browser profile has separate data
  Same profile = shared data across computers

Q: Is the data secure?
A: ✅ Not sent to any server
  ✅ Stored locally on your device
  ⚠️ Accessible to anyone with device access

Q: What if I accidentally delete a student?
A: Unfortunately, deletion is permanent
  Tips: Always confirm before deleting
  Future: Undo/Restore feature planned
