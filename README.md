# The Lighthouse Academy - Management System

A professional, modern web-based management system for **The Lighthouse Academy for English Language and IT**.

## Features

### 📊 Dashboard
- Overview of key statistics (total students, attendance rate, pending fees, departments)
- Recent activities feed
- Quick access buttons for common tasks

### 👥 Students Profile
- Complete student database with search functionality
- Filter by department and class
- View student details (roll no., name, contact, admission date, status)
- Add new students

### 📋 Attendance Management
- Track daily attendance
- View attendance by date, department, and class
- Record time in/out
- Add remarks for absences

### 💰 Fee Submission & Payment
- Monitor fee collection
- Track payment status (Paid, Pending, Partial)
- Record new payments
- Download payment receipts

### 📈 Reports & Analytics
- **Daily Reports**: Today's overview
- **Weekly Reports**: Weekly statistics and summaries
- **Monthly Reports**: Comprehensive monthly analytics
- Download reports in PDF format

### 📅 Calendar & Schedule
- Interactive calendar view
- Upcoming events and class schedules
- Event dates and timings
- Location information

### 🎓 New Admissions
- Track admission applications
- Monitor admission fees
- View application status (Approved, Pending, Rejected)
- Process new student admissions

### 🏢 Departments
- View all departments (English Language, IT & Programming, Web Development)
- Department statistics (students, courses, staff)
- Department details and management

## System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for Font Awesome icons
- JavaScript enabled

## Installation

1. Extract all files to a web server or local directory:
   - `index.html`
   - `style.css`
   - `script.js`

2. Open `index.html` in your web browser

## Usage Guide

### Navigation
- Use the **left sidebar** to navigate between different sections
- Click on any menu item to view that section
- On mobile devices, click the **hamburger menu** icon to toggle the sidebar

### Search & Filter
- Use the **search boxes** to find students or records
- Use **dropdown filters** to filter by department, class, or status
- Use **date pickers** to filter by specific dates

### Quick Actions
- **Add New Student**: Click "Add New Student" button to add a new student profile
- **Record Payment**: Use the "Record Payment" button to add fee submissions
- **Generate Reports**: Click "Download PDF" to export reports
- **View Details**: Click the eye icon to view complete information

### Keyboard Shortcuts
- **Ctrl/Cmd + K**: Focus on search box
- **Esc**: Close mobile sidebar

### Responsive Design
- Desktop: Full layout with sidebar navigation
- Tablet: Optimized grid layout
- Mobile: Collapsible sidebar with mobile-friendly interface

## Customization

### Changing Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary: #2563eb;
    --secondary: #7c3aed;
    /* ... more colors ... */
}
```

### Adding New Departments
Edit the departments section in `index.html` to add new department cards.

### Modifying Student Data
Update the table rows in the Students Profile section with your actual data.
