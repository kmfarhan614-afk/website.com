Management System - Quick Start Guide

🚀 Getting Started

Welcome to The Lighthouse Academy Management System! This guide will help you get started with all the features available in the system.

✓ Files Ready: All necessary files (HTML, CSS, JavaScript) are already set up and ready to use. Simply open index.html in your web browser to start using the system.
1

Open the Application

Double-click on index.html to open it in your default web browser, or right-click and select "Open with" to choose a specific browser.

2

Explore the Dashboard

You'll see the main dashboard with key statistics. The left sidebar contains navigation menu for all sections.

3

Navigate Between Sections

Click on any menu item in the sidebar (Students Profile, Attendance, Fee Submission, etc.) to switch between different modules.

4

Use Filters and Search

Use the search boxes and dropdown filters to find specific students, records, or information quickly.

💼 Common Tasks

How to Search for a Student

1

Click on "Students Profile" in the sidebar

2

Type the student name in the search box at the top

3

Results will filter automatically as you type

How to Check Attendance

1

Go to "Attendance" section from the menu

2

Select a date using the date picker

3

Filter by department if needed

4

View attendance status for all students on that date

How to View Fee Status

1

Navigate to "Fee Submission" section

2

Search for a student or filter by payment status

3

View total fee, paid amount, and pending balance

How to Generate Reports

1

Go to "Reports" section

2

Click on the report type tab (Daily, Weekly, or Monthly)

3

Click "Download PDF" to export the report

💡 Tips & Tricks

Keyboard Shortcut: Press Ctrl + K (or Cmd + K on Mac) to quickly focus on the search box from any page.
Mobile Access: The system is fully responsive! You can access it from mobile devices. Click the menu icon (☰) to toggle the sidebar on smaller screens.
Navigation History: Your last viewed section is automatically saved. When you return to the page, it will show the section you were last viewing.
Data Filtering: You can combine multiple filters (search + department + status) to narrow down results quickly.
